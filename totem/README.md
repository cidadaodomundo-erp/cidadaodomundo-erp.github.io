# Totem de autoatendimento — Cidadão do Mundo

App próprio para o totem JOOG (Android 14, tela 32" vertical 1080×1920).

- `app/` — app do totem (cardápio, carrinho, adicionais, vídeo de espera, TV de senhas). Node 18+, sem dependências.
- `saipos-teste/` — conector que envia pedidos **somente para a loja de teste do Saipos (HML 93936)**.

Situação em 16/11/2026: só teste. Sem pagamento real (TEF pendente), sem loja real do Saipos, depende de um computador ligado.
Configuração privada (chaves do Saipos) fica fora deste repositório e nunca deve ser adicionada aqui.
Origem: arquivos do computador BENTOIK, versão de 12/11/2026.
